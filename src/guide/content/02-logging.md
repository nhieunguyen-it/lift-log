# Logging a workout {#logging}

## Start a session {#logging-start}

On the Workout tab press **Start workout**, then **Add exercise** and pick one (search by name). The app keeps a single active session at a time, and it survives closing the app.

![Workout tab with an exercise card, a target chip and set rows](/guide/workout.png)

## Sets, reps and RIR {#logging-sets}

Each exercise card has rows with **weight, reps, RIR** and a **Done** checkbox. Press **Add set** for another row; new rows are pre-filled from earlier sets to save typing.

- **RIR** means reps in reserve: how many more good reps you could have done. Leave it empty if you did not track it.
- For bodyweight exercises the weight column is _added_ load (a belt or vest). Leave it empty for plain bodyweight.
- The row buttons duplicate or delete a set.

Tick **Done** when the set is finished. A set needs at least one rep before it can be marked done. Only done sets count toward your weekly volume.

> [!TIP]
> Tap the target chip at the top of a card to fill the next empty set with the suggested weight and reps. See Progression targets.

## Warm-ups {#logging-warmups}

Tick **Warm-up** on a set to mark it. Warm-up sets show a **W** instead of a number and never count toward volume or progression.

## Reorder, swap and remove {#logging-reorder}

The arrow buttons on an exercise card move it up or down. The swap button replaces the exercise with a similar one and keeps your sets (see Alternatives and swaps). The trash button removes the exercise; you are asked first if it has sets.

## Finish a workout {#logging-finish}

Press **Finish**. The dialog reminds you that only completed, non-warm-up sets count and shows a summary. Choose **Finish workout** to save it to History, or **Keep going**. **Discard workout** deletes the whole session.

## Forgotten sessions {#logging-stale}

If a session has been open for more than about half a day, a red prompt asks what to do. **Finish it** closes the workout at the time of your last completed set, so the duration is not inflated. **Discard it** deletes it.

## History {#logging-history}

History lists finished workouts, newest first. Tap one to open it. You can still edit sets, add or reorder exercises, or delete the workout there, and the weekly analysis updates to match.
